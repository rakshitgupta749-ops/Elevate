# Product Requirements Document (PRD)

# **Elevate**

## *Practice conversations. Improve professional confidence.*

---

# 1. Product Summary

## Product Name

**Elevate**

## Product Type

AI-powered professional role-play conversation simulator.

## Core Concept

Elevate allows users to practice real-world professional conversations by interacting with AI personas that behave like specific roles such as CTO, CEO, HR Manager, Sales Director, Client, or Interviewer.

Users define:

* What they want to practice
* Who they want to practice with
* The situation they want to simulate

The AI dynamically adopts that persona, understands the scenario, and conducts a realistic conversation.

---

# 2. Product Objective

Create a simple but powerful AI conversation platform where users can simulate high-pressure professional interactions and improve:

* Communication skills
* Interview performance
* Leadership conversations
* Negotiation ability
* Sales confidence
* Technical explanation skills

---

# 3. User Problem

Many people prepare for professional conversations using static content:

* Interview question lists
* Sales scripts
* Leadership articles
* Communication videos

However, real conversations require:

* Thinking on the spot
* Handling follow-up questions
* Explaining ideas clearly
* Responding under pressure

Elevate provides a realistic practice environment.


```json
[
{
"name":"Technical Interview",
"type":"technical"
}
]
```

---

## Get Roles

```
GET /roles
```

Response:

```json
[
{
"name":"CTO",
"description":"Technology leader"
}
]
```

---

## Create Session

```
POST /session
```

Request:

```json
{
"topic":"Technical Interview",
"role":"CTO",
"scenario":"Backend interview"
}
```

---

## Chat

```
POST /chat
```

Request:

```json
{
"session_id":"123",
"message":"My answer"
}
```

Response:

```json
{
"reply":"Follow-up question"
}
```

---

## Streaming Chat

```
WS /chat/{session_id}
```

Used for:

* Real-time typing effect
* Future voice support
